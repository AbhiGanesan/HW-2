HW2 Mapping: PSU Reported Crimes

Short Answer Questions

1. Ana and the Walker building. Ana wants to know which crimes are most prevalent near Walker. The task is to summarize the distribution of offense types for the incidents inside a small region, so the target is an attribute (offense category) within a spatial subset, and the action is to compare how common each category is. An idiom that would help is a map where Ana can select a radius around Walker, linked to a bar chart showing the count of incidents for each offense category in that selection. The bar lengths make the most common crimes easy to rank.

2. James and where a crime is common. James wants to know the areas where one particular crime is common. The task is to locate spatial hotspots for a single offense, so the action is to filter to that offense and then identify dense clusters, and the target is the spatial distribution of those incidents. An idiom that would help is a map with an offense filter combined with a density heat map (or clustered markers), so only the chosen crime is shown and the busiest areas stand out by color intensity.

Bonus Feature

I added a legend in the bottom right of the map that shows the color used for each offense category. Each legend item also has a checkbox that hides or shows the markers in that category, so it works as a filter.
